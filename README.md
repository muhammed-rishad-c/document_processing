# 📄 Mini Document Processing & RAG System

A lightweight, full-stack Retrieval-Augmented Generation (RAG) RESTful API built with **FastAPI**, **SQLAlchemy**, **PostgreSQL**, **Qdrant**, and **Google Gemini**. The system ingests text and PDF documents, automatically chunks and embeds passages into a vector space, performs hybrid relational/vector storage, and powers semantic search alongside context-grounded AI chat.

---

## ✨ Features

* **Multi-Format Ingestion**: Upload `.txt` and `.pdf` files with automatic text extraction and sanitization.
* **Smart Text Chunking**: Configurable chunk sizes and overlaps with token counting for precise context budgeting.
* **Dual-Database Architecture**:
  * **PostgreSQL**: Stores relational metadata, raw text chunks, and document statistics with full ACID compliance using **UUIDs** and native **JSONB** columns.
  * **Qdrant**: Stores dense vector embeddings for fast Approximate Nearest Neighbor (ANN) semantic search.
* **Semantic Search Endpoint**: Perform vector similarity searches across all documents or target a specific document by UUID.
* **Context-Grounded RAG Chat**: Ask questions about uploaded documents and receive answers generated by **Google Gemini** with full source attribution (document ID, chunk index, similarity score).
* **Cascading Cleanup**: Deleting a document permanently purges its records from PostgreSQL, vectors from Qdrant, and physical disk storage.

## 🏗️ Project Architecture & Tech Stack

* **Framework**: [FastAPI](https://fastapi.tiangolo.com/) (Python 3.10+)
* **Relational Database**: [PostgreSQL](https://www.postgresql.org/) (via SQLAlchemy ORM)
* **Vector Store**: [Qdrant](https://qdrant.tech/) (`qdrant-client`)
* **LLM & Embeddings**: [Google Gemini API](https://ai.google.dev/)
* **Data Validation**: [Pydantic V2](https://docs.pydantic.dev/)
* **Document Extraction**: `pypdf` & native Python text decoding
